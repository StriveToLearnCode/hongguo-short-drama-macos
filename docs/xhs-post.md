# 手机里的红果片单，终于搬上Mac了

手机刷到一部想看的剧，回到电脑却又得重新搜——我最想解决的就是这件事。

所以，这次把我维护的「红果短剧 Mac 版」更新到了 1.0，主打手机 × Mac 双端同步追剧。

Mac 登录同一红果账号，手机里收藏的剧、观看历史、预约和点赞记录，就能在 Mac 里查看；Mac 的新操作也可以回写账号云记录。换个屏幕，少折腾一遍。

这版最想让你试试的是：
📚 把手机片单带到 Mac，不用重新整理收藏
📺 用大屏接着追，1080P / 720P / 540P / 360P 按本集片源选择
🪟 桌面留给正事，好故事放进小窗；回消息、查资料时随时接着看，需要时打开置顶
🔎 搜索联想、分享链接直达、分季选集，找剧和切集更顺手

首次登录会自动准备本机环境，旧 Mac 游客记录上传前由你选择；升级保留原有收藏、历史与设置。不登录也可以直接用游客模式看。
